# allctrl grafikkpakke

13 moduler, fire varianter per modul.

- **svg/**: eksisterende vektororiginaler fra logos/v2 i jojofos-maker/allctrl. Symbol, appikon, liggende logo og logo med navn under.
- **png/**: 1024 piksler bredde. Proporsjoner og transparens fra SVG beholdes.
- **webp/**: opptil 512 piksler. Kompakt format for nettsider.
- **pdf/**: vektoreksport med tekst gjort til kurver for deling og trykk. RGB, ikke en ferdig CMYK-trykkfil.
- **icons/**: appikon i 512, 192, 180 og 32 piksler, samt favicon i ICO med 16/32/48 piksler. Appikonet har mørk bakgrunn.
- **originals/**: de ti PNG-vedleggene, uendret. Disse viser den opprinnelige rasterprofilen.

SVG-serien v2 er tidligere etablert grafikk og er brukt på nettsiden. Den kan avvike litt fra PNG-referansene. Ingen logoer er nytegnet i denne leveransen.

På GitHub ligger eksportene samlet per modul i `packages/`. Pakkene har undermappene som er beskrevet over. SVG-filer ligger også direkte i `svg/`.
